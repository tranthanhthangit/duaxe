# Original design assets

The three designs are visible in the conversation, but no image binaries were supplied in the accessible attachment directory. Do not generate or substitute other images.

Place the original files here, keeping their aspect ratio:

- home-background.png — original home artwork, with its existing logo and child drivers.
- create-room-background.png — original teacher artwork with wooden title.
- race-background.png — race **art reference**, not a second road behind Phaser.

Home and teacher pages automatically use the first two when available. They use the existing pastel UI when files are missing, without broken image icons. Do not put real student photos in this folder.

Phaser recreates the environment from the race reference while retaining its own three-lane road and world-coordinate finish gate. The full race image is intentionally not overlaid: its fixed horizon and road would disagree with the dynamic camera.

No VNI-Avo font file was found. The UI uses system fonts with Vietnamese support, without downloading fonts.
